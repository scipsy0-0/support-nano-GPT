Actions with files and folders
Basic actions with a file or folder are displayed in the top panel or in the context menu. To view additional actions, click the icon. All actions taken with files and folders are saved in History.
Note
If you open Yandex Disk in a small window, some file actions may move from the top panel to the context menu.

Actions with files and folders
View information about a file
To get all information about a file or folder, click the icon in the top left corner. The menu displays:
- Name (to change it, click Rename in the top panel or from the context menu).
- Size.
- Date updated.
- Number of files (for folders).
- Number of views and downloads (for a public file or folder).
To view file sizes within a folder, display them as a list: select the corresponding display option in the top right corner. You will be able to see the file size in the right column.

Actions with files and folders
Sort the file list
You can sort the list of files in a folder. Click Sort to see the available options.

Actions with files and folders
Select multiple files or folders
To manage several files at once, select the area where they are located. All group operations are available on the panel. To select several files in a row, click the first and last file in a range while holding down the Shift key. To select several separate files, hold the Ctrl key for Windows or ⌘ for Mac OS X while selecting the files.
Note
You can select no more than 500 files at a time.
Tips for organizing space on Yandex Disk

Viewing files and folders
You can view the files you've uploaded to Yandex Disk in the web interface without installing any software. The following file formats are supported:
- Documents: DOC/DOCX, XLS/XLSX, PPT/PPTX, ODT, ODS, ODP, CSV, RTF, TXT, PDF.
- Images: JPG, PNG, GIF, BMP, TIFF, NEF, EPS, PSD, AI.
- Archives: ZIP, RAR, TAR.
- eBooks: FB2, DJVU.
- Audio and video: all popular formats.

Viewing files and folders

To view the number of pages in a document or to switch to fullscreen mode, hover over the bottom of the screen for the corresponding icon to appear.

Viewing files and folders
Viewing images
Double-click an image to view it in full-screen mode.
In this mode, you can view information about the image, as well as share, edit, rename, copy, download, and delete the image (using buttons in the top right corner). To open the original image or add it to an album, click and select the appropriate menu item. To hide the icons, click the image.
To exit image-viewing mode, press the Esc key or close the window.

Viewing files and folders
Image quality has decreased
Images are stored on Yandex Disk in their original quality. They are not compressed during upload. However, Yandex Disk creates previews in a lower resolution to view on the website, in order to reduce traffic and make user experience on Yandex Disk smoother. You'll see a preview if the file size doesn't exceed 50 MB. To view an image in its original quality, download it to your computer.

Viewing files and folders
I'm a photographer, and my photos are displayed on Yandex Disk in wrong colors
This is most likely because an incorrect color profile was set when shooting or processing the photos. To display proper colors in photos in web browsers and most image viewing programs, you need to set the sRGB color profile. You can do this in the camera settings (when shooting in JPEG) or your image editor settings (when processing or converting from RAW to JPEG).
The color profile of a photo can be changed at any time in the image editor. To do this in Adobe Photoshop, open the menu Edit → Convert to Profile, and in the Destination space field, select sRGB. After saving, proper colors will be displayed.

Problems with files
Files do not open or are broken
If your files on Yandex Disk don't open and there are duplicates with suspicious extensions, it is likely that your computer is infected with an encryption virus. Such viruses modify all files on the computer. As the Yandex Disk program syncs the changes, files were changed on the Yandex Disk server as well. Unfortunately, Yandex Disk can't distinguish between the actions of a virus and a user.
To restore files:
1. Please check your computer for viruses with free anti-virus programs such as CureIt! from Dr. Web or Virus Removal Tool from the Kaspersky Lab.
2. Change your password in the Yandex ID settings, link your phone number to the account, and change your security question and answer. It's better to do this after the virus scan.
3. Try searching for files in the Trash. If the virus deleted the original files and replaced them with broken ones, the original files might be found in the Trash on Yandex Disk. If it has been less than 30 days since the virus activated, files may still be in the Trash.
4. If the original files are not in the Trash, most likely, the virus didn't delete but encrypted them. Try restoring old versions of encrypted files from the version history. If there are no old versions in the version history, it's impossible to restore the files.

Yandex Disk files are missing
If you can't find your files on Yandex Disk, they probably ended up in another folder or the Trash. If you remember the file name, extension, or body text, try searching your Yandex Disk folders and the Trash for it.
You can also look through your history to see what happened with your missing files.
Note
If you have several accounts on Yandex, make sure that you are logged in to the account where you want to find files. You may be looking for files on the wrong account.

Yandex Disk files are missing
Restore files from the Trash
If your missing files are not in the Trash, it's possible that they were deleted if more than a month has elapsed (the Trash is automatically emptied after a month). If that's the case, those files can't be restored.
If your files were deleted less than a month ago, you can restore them:
1. Open the Trash.
2. Select the files you want to restore.
3. In the top panel, click Restore.

Yandex Disk files are missing
Why could my files be deleted from Yandex Disk if I didn't delete them
Files were deleted from the Yandex Disk folder on your computer
When you delete a file from the Yandex Disk folder on your computer, it is automatically moved to the Trash on the Yandex Disk server. After a month from the moment of moving the files to the Trash, the Trash is automatically cleared, and the files are deleted forever.
If you want your files to be available only through the browser so that they don't take up space on your computer, set up selective sync (see the instructions for Windows and macOS).

Yandex Disk files are missing
Why could my files be deleted from Yandex Disk if I didn't delete them
Files were deleted from the mobile app
If you delete a file in the mobile app, it is automatically moved to the Trash on the Yandex Disk server. A month after the files are moved to the Trash, the Trash is automatically cleared, and the files are deleted forever.

Yandex Disk files are missing
Why could my files be deleted from Yandex Disk if I didn't delete them
Files were deleted by one of the people who have access to your shared folder
If you have a shared folder and you've given others edit access, it means they can change and delete files in that folder.
If someone who has access to your shared folder deletes a file from it, then the file will automatically move to the Trash of both the person who deleted it and the folder's owner. A month after the files are moved to the Trash, the Trash is automatically cleared, and the files are deleted forever.
The files are also permanently deleted for anyone else with access to the folder.
